# RaZeRektU Website

Free static one-page site for RaZeRektU.

## Deploy for free
1. Create a GitHub account if you don't have one.
2. Create a new public repository named `razerektu.github.io` (if that username is available).
3. Upload `index.html`.
4. In repository Settings -> Pages, enable GitHub Pages from the main branch.
5. Your site will be available at `https://razerektu.github.io/`.

You can later buy a custom domain and connect it without redesigning the site.
